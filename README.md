# 🎓 EduAI - Умный генератор лекций и интерактивных игр

## ✨ Возможности
- 📖 Генерация структурированных лекций
- 📝 Викторины
- ✅ Правда или ложь
- 🃏 Найди пару
- 💻 Практические задания по HTML/CSS

## 🔑 Получение API ключа
1. Зарегистрируйтесь на [OpenRouter](https://openrouter.ai/)
2. Получите бесплатный API ключ
3. Вставьте ключ в боковую панель или создайте `.env` файл
